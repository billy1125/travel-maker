回上層：[README.md](../README.md)｜[itinerary.md](../itinerary.md)

> **這一層只記錄拍攝資訊，不改動行程。** 每個檔案都有「與本次行程的對應」一節，標明哪些點落在既有動線上、哪些需要額外加排；要把拍攝點排進行程，仍須經討論後由 `/update-itinerary` 寫入 `days/`。
